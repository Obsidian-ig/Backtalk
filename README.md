# Backtalk
An upcoming api documentation tool! Still in early development!

Created with Blazor Webassembly, which allows the project to work in your web browser even when you are offline!
For now, the entire purpose of BackTalk is to be a super simple manual API Documentation creation tool. I got sick of all the available options for that being annoying to work with and get setup and so instead of dealing with all of that, I decided to make my own! That is what BackTalk is and what it is for. It's whole existence sprouted from the fact that traditional api documentation tools are annoying to use and setup or they don't actually create literal documentation of your API schema. Blazor not only lets you easily create and edit API endpoints for a majority of projects, but also automatically creates the documentation pages for you, without you needing to do anything other than actually create the endpoints in the editor! It does the rest for you!

BackTalk is completely open-source and anyone can make additions/changes to it if they wish - as long as said changes and additions are inline with the liscense.
